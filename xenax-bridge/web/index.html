Connection

How to put a Windows laptop on the drive's network
  1. Plug the laptop's Ethernet port (or a USB-Ethernet adapter) into the drive, directly or through a switch.
  2. Open Settings → Network & internet → Ethernet and choose that adapter.
  3. Next to IP assignment click Edit → Manual → turn on IPv4.
  4. Enter an unused address in the drive's subnet, e.g. 192.168.2.10, subnet mask 255.255.255.0. Leave gateway and DNS empty. Save.
  5. Come back here. The adapter should appear above with a ✓.

Changing adapter settings may need admin rights on managed laptops. If it's blocked, ask IT to give that adapter a static address, or to put the drive on a subnet your laptop already uses.
